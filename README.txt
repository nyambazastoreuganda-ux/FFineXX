
FFineXX — Short Video Social Platform

ABOUT
FFineXX is a short-video social platform project with a dark,
modern design and pink/purple accents.

CURRENT FEATURES
- Home feed interface
- For You and Following navigation
- Demo like and follow interactions
- Responsive layout for desktop and mobile
- Express server

PLANNED FEATURES
- User registration and login
- Video uploads and playback
- Comments and sharing
- Search and creator profiles
- Notifications and messaging
- Admin dashboard and moderation
- LIVE streaming

TECHNOLOGY
- HTML
- CSS
- JavaScript
- Node.js
- Express

START
Install Node.js 18 or newer.
Run npm install.
Run npm start.
Open http://localhost:3000 in your browser.

NOTE
Features listed as planned are not functional until implemented.
